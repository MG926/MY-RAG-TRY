Python 虚拟环境操作指南
=========================


【创建虚拟环境】
-----------------------------------------------------------

1. 创建：
   python -m venv 环境名

   示例：python -m venv myenv

2. 激活（需先 cd 到环境文件夹的上级目录）：

    Windows CMD：
    环境名\Scripts\activate.bat

    Windows PowerShell：
    环境名\Scripts\Activate.ps1
    或 .\环境名\Scripts\Activate.ps1

    Mac/Linux：
    source 环境名/bin/activate

    若 PowerShell 提示"无法加载文件...禁止运行脚本"，先执行：
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

    也可用绝对路径激活（无需 cd）：
    F:\项目\环境名\Scripts\activate

3. 激活后命令行前会出现 (环境名) 标识，表示已进入虚拟环境

4. 退出虚拟环境：
   deactivate


【删除虚拟环境】
-----------------------------------------------------------

1. 先退出虚拟环境（若已激活）：
   deactivate

2. 直接删除虚拟环境文件夹即可（无副作用）：
   rmdir /s 环境名        # Windows
   rm -rf 环境名          # Mac/Linux


【导出/还原依赖】
-----------------------------------------------------------

1. 导出已安装的包到文件：
   pip freeze > requirements.txt

2. 从文件安装依赖：
   pip install -r requirements.txt


【清华镜像源】
-----------------------------------------------------------

1. 临时使用清华源安装包：
   pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple

2. 永久设为默认源（推荐）：
   pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

3. 验证是否配置成功：
   pip config list

4. 换回官方源：
   pip config unset global.index-url

5. 也可写入配置文件（Windows: %APPDATA%\pip\pip.ini / Linux: ~/.pip/pip.conf）：
   [global]
   index-url = https://pypi.tuna.tsinghua.edu.cn/simple

6. 其他国内镜像源备选：
   阿里云   https://mirrors.aliyun.com/pypi/simple
   中科大   https://pypi.mirrors.ustc.edu.cn/simple
   豆瓣     https://pypi.douban.com/simple
